# 痒痒鼠课程表 · 阴阳师打卡清单

> 一个纯静态、零依赖的阴阳师日常 / 周常 / 活动打卡网页。勾选即记录，自动统计勾玉、蓝票、黑蛋、黑碎收益，随时看清**完成了哪些、还差哪些**。

清单结构与交互参考 B 站「本命英雄拉克丝」的痒痒鼠打卡工具；任务攻略备注整理自《2025 痒痒鼠课程表 by 妹酱的小本本》。

## 功能特性

### 多账号

顶部提供 `ID1` ~ `ID6` 六个账号槽位，**双击账号名即可重命名**。每个账号的打卡进度、收益记录、打卡天数完全独立，互不影响，适合多开或帮朋友记录。

### 六大板块

页面按业务拆成六个标签页，每类任务有各自的重置节奏：

| 板块 | 内容 | 重置规则 |
| --- | --- | --- |
| 每日任务 | 22 项，含一键签到、悬赏任务、寄养等分组 | 每日 00:00 自动重置 |
| 每周任务 | 25 项，含寮活动、固定奖励、兑换奖励、战斗奖励 | 每周一 00:00 自动重置 |
| 特殊兑换 | 神龛兑换等 | 每双数周周四自动刷新 |
| 版本福利及活动 | 当期活动，7 项 | 活动期内打卡，到期自动清除 |
| 商店购买 | 永久勾玉卡、月度运势礼 | 勾选后按日结算收益 |
| 收益统计 | 手动输入 + 自动汇总 | 按日归档 |

### 三种打卡控件

1. **普通勾选**：点击任务行或复选框即可完成 / 取消，完成后置灰划线。
2. **数字步进器**：悬赏、寄养、勋章商店等带 `▲▼` 的项，可按 `step` 增减，数值自动折算成收益；部分项提供 `20 / 40 / 60` 之类的快捷值按钮。
3. **标签打卡**：寮活动按「周一 ~ 周日」、活动按日期（如 `10.5 ~ 10.11`）逐格点亮，**全部点亮才算完成**。

### 效率功能

- **一键全部完成**：「一键签到内容」分组内有专属按钮，工具条上还有「一键完成本页」。
- **折叠已完成项目**：开启后只显示待办，一眼看清还差什么。
- **实时倒计时**：顶部显示距每日重置的剩余时间。
- **收益自动结算**：勾选项的固定收益 + 步进器数值 + 商店每日收益 + 手动输入，实时汇总为**今日 / 昨日 / 本周 / 累计**四档。
- **已打卡天数**：只要有任意打卡记录，当天即计入累计天数。

### 工程特性

- **零依赖、零构建**：纯原生 HTML + CSS + JavaScript，没有任何 npm 依赖或打包步骤。
- **本地持久化**：全部数据存在浏览器 `localStorage`，刷新、关闭浏览器都不丢失，**不联网、不上传、不共享**。
- **响应式**：手机端单列布局，单手可操作。
- **可访问性**：复选框、步进器均带 `aria-label` / `role`，支持键盘操作。

## 部署到 Vercel

本项目是纯静态站点，**无需任何构建配置**，三种方式任选：

> **本项目部署说明**
>
> - **Vercel 登录方式**：使用 **Google 账号快捷登录**（Sign in with Google），无需单独注册 Vercel 账号
> - **导入仓库**：`asta0511/onmyoji-checklist`
> - 导入时 Framework Preset 选 `Other`，Build Command 与 Output Directory 均留空

### 方式一：命令行（最快）

```bash
npm i -g vercel
cd onmyoji-checklist
vercel          # 首次会引导登录，一路回车即可
vercel --prod   # 发布到正式环境
```

### 方式二：网页拖拽

打开 <https://vercel.com/new>，把整个文件夹拖进去即可。

### 方式三：GitHub 导入

在 Vercel 中 Import 本仓库，然后：

- **Framework Preset**：`Other`
- **Build Command**：留空
- **Output Directory**：留空

直接 Deploy 即可。

> 其他静态托管（GitHub Pages、Netlify、Cloudflare Pages）同样开箱可用。

## 自定义清单

`data.js` 的结构如下：

```js
window.ONMYOJI_DATA = {
  version: 'v1.0.0',
  resetHour: 0,                                  // 每天几点算“新的一天”
  accounts: ['ID1', 'ID2', 'ID3', 'ID4', 'ID5', 'ID6'],
  resourceLabels: { jade: '勾玉', ticket: '蓝票', egg: '黑蛋', shard: '黑碎' },

  sections: [
    {
      id: 'daily',                               // 板块 id
      title: '每日任务',
      resetHint: '每日 00:00 自动重置',
      reset: 'daily',                            // daily | weekly | biweekly | activity
      groups: [
        {
          id: 'g-signin',
          title: '一键签到内容',
          batch: true,                           // 显示「一键全部完成」按钮
          items: [
            { id: 'd-signin', name: '签到' }
          ]
        }
      ]
    }
  ]
};
```

### item 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | **必填，全局唯一**。打卡状态就是按 id 保存的，改动 id 会丢失对应记录 |
| `name` | string | 任务名 |
| `note` | string | 备注 / 攻略提示，显示在任务名下方 |
| `gain` | object | 完成后计入的收益，如 `{ jade: 20, ticket: 1, egg: 1, shard: 1 }` |
| `counters` | array | 行内数字步进器，见下方示例 |
| `days` | array | 星期标签，如 `['周一', '周二']` |
| `labels` | array | 自定义标签（活动日期 / 场次等），如 `['10.5', '10.6']` |
| `period` | object | 活动有效期 `{ start, end }`，过期后自动隐藏并清除记录 |
| `kind` | string | `persist` 永不自重置；`monthly` 每月重置 |

### 示例

```js
// 带收益的普通任务
{ id: 'd-flower', name: '花合战 100', gain: { jade: 20 } }

// 带步进器和快捷值的任务：每 1 点折算 1 勾玉
{ id: 'd-region', name: '地域鬼王',
  note: '萌新打 1 级热门鬼王',
  counters: [{ unit: '勾玉', step: 20, max: 60,
               presets: [20, 40, 60], per: { jade: 1 } }] }

// 多单位步进器
{ id: 'w-liao-shop', name: '寮商店',
  counters: [
    { unit: '蓝票', step: 1, max: 2, per: { ticket: 1 } },
    { unit: '黑碎', step: 1, max: 3, per: { shard: 1 } }
  ] }

// 星期标签打卡
{ id: 'w-hunt', name: '狩猎战', days: ['周一', '周二', '周三', '周四'] }

// 限时活动，过期自动清除
{ id: 'a-qinfei', name: '寝肥合战',
  period: { start: '2026-10-05', end: '2026-10-11' },
  labels: ['10.5', '10.6', '10.7', '10.8', '10.9', '10.10', '10.11'] }

// 永久生效、永不重置
{ id: 'p-jade-card', name: '永久勾玉卡', kind: 'persist', gain: { jade: 20 } }
```

> **注意**：`counters` 类任务不显示复选框，只要任意一个步进器数值大于 0 就视为完成。

## 数据与重置规则

### 计数日

- **一日** = 当日 `00:00` ~ 次日 `00:00`
- **一周** = 周一 `00:00` ~ 次周一 `00:00`
- 每日任务、商店购买在每天 00:00 自动清空
- 每周任务在每周一 00:00 自动清空
- 特殊兑换在每个双数周的周四刷新
- 活动板块的条目过期后自动隐藏并清除记录

### 收益结算

今日收益 = 已完成任务的固定 `gain` + 步进器数值 × `per` + 商店每日收益 + 手动输入。

每次状态变化都会把当日收益写入历史归档，用于计算昨日、本周与累计。**累计劳动所得与已打卡天数不会因为重置而丢失。**

### 重置按钮

| 按钮 | 作用 |
| --- | --- |
| 重置本日打卡 | 清空「每日任务」与「商店购买」的今日打卡 |
| 重置本页 | 清空当前所在板块的勾选与数字 |
| 全部重置 | 清空当前账号的全部勾选、数字与手动收益，**保留**已打卡天数与劳动所得历史 |

### 存储

数据保存在浏览器 `localStorage`，键名：

- `onmyoji-checklist-v2` —— 账号数据
- `onmyoji-checklist-prefs-v2` —— 界面偏好（当前标签页、是否折叠已完成）

## 常见问题

**Q：换电脑 / 换浏览器数据会同步吗？**
不会。数据只存在当前浏览器，不联网、不上传。换设备或清理缓存会重置。

**Q：活动板块为什么是空的？**
活动条目带有 `period` 有效期，过期后会自动隐藏并清除。新活动需要手动在 `data.js` 里补充。

**Q：怎么加一个新任务？**
在 `data.js` 对应板块的 `groups[].items` 里加一条，保证 `id` 唯一即可，刷新页面生效。

**Q：可以改每日重置时间吗？**
可以，修改 `data.js` 里的 `resetHour`（默认 `0` 表示 00:00）。

**Q：为什么数字步进器没有勾选框？**
步进器本身就是完成状态的载体——数值大于 0 即为完成，避免「勾了但没填数量」的歧义。
